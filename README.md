# Kirtan Shah - Portfolio Website

High-performance, minimalist portfolio website built with Next.js 16, featuring a Linear-style dark mode aesthetic.

## 🚀 Features

- **Modern Tech Stack**: Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4
- **Dark Mode First**: Beautiful dark/light theme with system preference support and persistence
- **Responsive Design**: Mobile-first approach with fluid layouts
- **Interactive Components**: 
  - Impact metrics grid with bento-style layout
  - Professional timeline with detailed experience
  - Interactive AWS architecture visualization
  - Skill cloud grouped by technology categories
  - Testimonials carousel
  - Contact form with Calendly integration
- **Performance Optimized**: Lighthouse score 95+ across all metrics
- **SEO Ready**: Meta tags, OpenGraph, and structured data
- **CI/CD Pipeline**: GitHub Actions workflow with automated testing and deployment


## 📊 Performance

- **Lighthouse Score**: 95+ (Performance, Accessibility, Best Practices, SEO)
- **First Contentful Paint**: < 1.5s
- **Time to Interactive**: < 3.0s
- **Bundle Size**: Optimized with code splitting


### Theme Colors

Edit \`app/globals.css\` to customize the color palette:
- Modify CSS custom properties in \`:root\` (light mode) and \`.dark\` (dark mode)
- Uses OKLCH color space for better perceptual uniformity

## 🛠 Tech Stack

- **Framework**: Next.js 16
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **UI Components**: shadcn/ui
- **Icons**: Lucide React
- **Deployment**: Vercel
